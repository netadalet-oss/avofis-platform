Kaynak 453 işlevin hepsi yukarıdaki modüllerde korunmuştur. Burada her modülün L1 veri nesnesi, risk sınıfı, tenant/dosya ilişkisi ve sentetik yetki kuralı görülebilir.

Doğrulama sınırı: Bu önizleme etkileşimli, çevrimdışı tasarım ve sentetik referans katmanıdır. Gerçek PostgreSQL RLS, kimlik sağlayıcı, Android APK, hukukî karar veya üretim yetkisi değildir. Örnek persona tamamen kurgusaldır.

L1 • Yetki kararı simülatörü

Kayıt erişimi hangi koşulda reddedilir?

Giriş, gerçek oturum veya dosya aktarımı yapılmaz. Kurgusal bir tenant/dosya kaydına yönelik politika kararı simüle edilir.

Sentetik SQLite referans kodunda bu kararların olumsuz ve olumlu durumları ayrı test edilmiştir. Bu ekran test ortamına bağlı değildir.

L2 • Tüm ürün • 14 modül

Kimlik · API · veri işlemleri · yetki sınırı

Özgün 453 işlev kimliği üstteki modül gezgininde yer alır. Aşağıda bütün modüller için L2 sentetik rota sözleşmesi ve kullanıcı rolüne göre işlem akışını inceleyebilirsiniz.

Çevrimdışı etkileşimli prototip. Bu ekran gerçek sunucuya, PostgreSQL'e, hukukî dosyaya veya Android APK'ya bağlanmaz. Simülatör sonuçları kanıt niteliğinde değildir; ayrı Python WSGI/SQLite testleri gerçek yerel test kanıtıdır.
Modül ve işlem seçerek sentetik sonucu görüntüleyin.

L2 yerel test kapsamı: tenant / dosya sahibi / modül ataması / MFA / oturum iptali / iyimser sürüm kontrolü / JSON boyut ve alan sınırları / imzalı, kısa ömürlü sentetik belge referansı. Tarihî A4 102 API kimliği ayrıca korunmuştur, bu 102 rotanın üretimde uygulandığı iddia edilmez.
