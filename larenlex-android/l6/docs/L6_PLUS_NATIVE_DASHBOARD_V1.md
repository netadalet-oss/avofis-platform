# LarenLex: New native navigation and explicit limits

The first screen is now a genuine native navigation dashboard with navy/gold visual hierarchy, quick access to the working offline DOCX/PDF editor, accent-insensitive search across the 453 canonical items, bookmarks of public LX identifiers, and accessible module/group/feature cards. The old MainActivity is no longer exposed as the launcher. Existing source modules and unique identifiers are unchanged.

This is interface/navigation work, not fulfillment of the 453 domain requirements. User login, persistent case records, server authorization, Dutch legal review, financial operations, IND/Rechtspraak integrations, and all independent acceptance gates remain unavailable. Bookmarks store **only LX IDs** locally, not client data. No INTERNET permission is granted. No production signing or publication is authorized.
